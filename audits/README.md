# Audits

This directory contains public numerical-certification, ingest, interpretation, formal-closeout, provenance, environment, and release-integrity records.

The original v1.0.0 M1--M5 audit chain remains unchanged. v1.1.0 adds public records for:

- H1-0012 formal closeout of the motivating direction-level decomposition;
- H1-0007 formal closeout of the development-stage exact ALiBi control;
- A52 raw-provenance verification and reconstruction/closeout provenance;
- A52 implementation-only IC04/IC05 records, which do not alter the scientific design or reported estimands.

The audit layer distinguishes scientific results from implementation, packaging, numerical-certification, and release artifacts. No non-scientific publication correspondence or internal manuscript-governance material is promoted here.
